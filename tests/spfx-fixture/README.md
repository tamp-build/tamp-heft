# SPFx integration fixture

A stock SharePoint Framework 1.24.1 solution with one Form Customizer (`FixtureForm`), generated by
`@microsoft/generator-sharepoint` 1.24.1 (`--component-type extension --extension-type FormCustomizer
--framework none`). It exists so `HeftDevServer` can be tested against a real `heft start`
(see `tests/Tamp.Heft.V1.Tests/RealSpfxDevServerTests.cs` and `.github/workflows/spfx-integration.yml`).

Don't edit it by hand beyond what the tests need. To move to a newer SPFx, regenerate it with the newer
generator, keep the solution and component names, and commit the new `package-lock.json`.

```bash
npm ci
TAMP_HEFT_SPFX_FIXTURE=$PWD dotnet test ../../Tamp.Heft.slnx --filter "FullyQualifiedName~RealSpfx"
```
